# Elecciones Globales

Mapa interactivo de las elecciones del mundo, coloreado según la relación de cada gobierno con el gobierno argentino actual.

- `index.html`: la página.
- `data.json`: fichas por país, calendario y resultados recientes.
- `world.json`: mapa base (world-atlas, countries-50m).
- `preview.png`: vista previa para compartir (1200×630).

Sitio estático, sin compilación: Netlify publica la raíz del repositorio.
